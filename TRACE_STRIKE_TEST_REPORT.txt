--------------------------------------------------
ERROS ENCONTRADOS
--------------------------------------------------

Arquivo: src/core/game.js
Linha: bindUI, chamada requestPointerLock
Mensagem: WrongDocumentError: The root document of this element is not valid for pointer lock.
Contexto: O navegador embutido do VS Code rejeitou o pedido automático de pointer lock ao clicar em START MISSION.
Impacto: Erro de página no primeiro teste; a partida e o HUD continuaram funcionando.
Possível causa: O Canvas não pertence a um documento elegível para pointer lock no navegador embutido.
Correção: O pedido agora é envolvido por try/catch e a Promise rejeitada recebe catch vazio. O jogo continua funcional sem pointer lock.

Arquivo: ambiente
Linha: comando de inicialização
Mensagem: python : The term 'python' is not recognized as the name of a cmdlet, function, script file, or executable program.
Contexto: Tentativa de executar python -m http.server 8000.
Impacto: Python não pôde fornecer o servidor local.
Possível causa: Python não instalado ou ausente no PATH.
Correção: Servidor estático equivalente criado com o módulo nativo http do Node.js.
